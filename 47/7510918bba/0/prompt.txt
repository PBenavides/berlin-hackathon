## Full Spec Constraints
[
  "Backend uses FastAPI + SQLAlchemy with PostgreSQL 16; SQLite not supported",
  "Frontend uses Next.js 14 App Router with TypeScript and TailwindCSS",
  "All API responses must use camelCase field names (backend must alias from snake_case)",
  "Proposal resource is internal only \u2014 never exposed on the /api surface",
  "Stable string IDs required for seed data to match frontend deep links",

  "Error envelope shape {error, code, status} is a contract obligation on every endpoint",
