  "Write tools follow the proposal-envelope pattern \u2014 they propose actions for human confirmation, never execute directly",
  "The SSE streaming infrastructure already exists in the chat engine \u2014 reuse it for action streaming rather than building a parallel system",
  "The seed service must remain idempotent \u2014 safe to run multiple times without duplicating data",
  "The frontend is a Next.js 15 app in a pnpm monorepo with shadcn/ui components \u2014 all new UI must use this stack",
  "The backend uses SQLAlchemy with Alembic migrations and PostgreSQL \u2014 new models require proper migrations",
  "All API responses must follow the existing standardized format with camelCase serialization",
  "The existing /dev/reset endpoint drops all tables \u2014 it must be extended to handle any new models/tables",
  "Context files use a 4-layer markdown format (vendor/owner/building/property) \u2014 additions must respect this structure",
  "The agent has a 50-turn budget per invocation (HERMES_MAX_TURNS) \u2014 batch processing must manage this per-ticket"
